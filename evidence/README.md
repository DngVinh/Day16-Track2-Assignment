# Evidence checklist

Các file trong thư mục này là bản ghi dạng text và screenshot để đối chiếu khi nộp bài.

- `01-benchmark.png`: screenshot terminal chạy benchmark.
- `02-resource-usage.png`: screenshot CPU/RAM/network của VM.
- `03-billing.png`: screenshot GCP Billing Reports.
- `benchmark_terminal.txt`: output đầy đủ của benchmark.
- `resource_snapshot.txt`: trạng thái VM và CPU/RAM/network.
- `billing_status.txt`: trạng thái Billing của project và ghi chú thời điểm báo cáo chưa cập nhật.

Deliverables vẫn nên kèm screenshot terminal benchmark, screenshot resource usage và screenshot Billing Reports theo README.
